# 使用边界 / Acceptable Use

本项目的作者只把它当作**个人自用**的工具发布，**不授权也不支持任何其他用途**。

This project is published **for personal, self-hosted use only**. No other use is authorised or supported by its authors.

---

## 允许的用途

- 你在**自己拥有或自己管理**的服务器上部署，连接**你自己**的微信机器人账号
- 供**你自己一个人**与自己的 DSH 对话：发消息、发图片、发文件、收早报
- 阅读、学习、修改代码供自己使用

## 明确禁止的用途

1. **对外提供服务**：把机器人当成面向他人/公众的服务、客服系统、群发工具
2. **骚扰与滥用**：给他人发送未经请求的消息、广告、营销内容，或任何形式的骚扰
3. **侵犯隐私**：抓取、窥探、存储他人的聊天内容或个人信息；把本工具用于监视他人
4. **绕过平台规则**：以自动化方式规避微信/腾讯的服务条款、风控或限制
5. **非本人账号**：连接不属于你的账号，或替他人托管其账号
6. **违法用途**：任何违反当地法律法规的用途；以及批量养号、刷量、诈骗等行为
7. **二次分发为服务**：把本工具包装成对外售卖或对外运营的服务（代码本身依 MIT 许可，但作者不为这类用途提供任何支持，也不承担任何责任）

## 为什么写这一段

这个桥接依赖的是**微信机器人网关**，它的正常运作前提是「一个主人、一个机器人、自己跟自己用」。一旦用于群发、营销或替他人服务：

- 极可能触发平台风控，**账号被封**，损失由使用者自负
- 会给他人带来骚扰，也可能涉及隐私与法律问题

## 使用者的责任

- 你**独自承担**部署、使用本工具产生的一切后果
- 请自行确认你的用法符合所在地区的法律、以及微信/腾讯的服务条款
- 作者不对任何滥用行为、账号封禁、数据丢失或法律纠纷负责

## 安全提醒

- **只把 `allowFrom` 设成你自己的微信 id**（项目默认就是这么设计的）。留空或设成 `"*"` 意味着任何能找到这个机器人的账号都会得到回复
- API key、登录凭据（`credentials.json`）、`.env` 不要提交到任何仓库
- 反向代理务必加上访问控制（例如客户端证书），别把界面裸奔在公网
